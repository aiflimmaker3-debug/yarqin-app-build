# «تەپەككۇر بۇلىقى» نى رەسمىي Windows `Setup.exe` قاچىلاش ھۆججىتى قىلىپ چىقىرىش قوللانمىسى

بۇ تۈرگە رەسمىي ئۈستەلئۈستى پىروگراممىسى (`Tepekkur-Buliqi-Setup-1.0.0.exe`) قۇراشتۇرۇش ئۈچۈن كېرەكلىك بارلىق Electron سەپلىمىلىرى، Windows `.ico` بەلگىسى ۋە NSIS قاچىلاش قائىدىلىرى تولۇق تەييارلانغان.

## تەلەپ قىلىنىدىغان مۇھىت
- Windows 10 ياكى Windows 11
- **Node.js 20+** (ئورگان تور بېتىدىن قاچىلاڭ: https://nodejs.org)

## 3 قەدەمدە `Setup.exe` ياساش

تۈر قىسقۇچىنى ئۆز كومپيۇتېرىڭىزغا چۈشۈرۈپ، شۇ قىسقۇچ ئىچىدە تېرمىنال (PowerShell ياكى CMD) ئېچىپ تۆۋەندىكى بۇيرۇقلارنى ئىجرا قىلىڭ:

```bash
# 1. بارلىق يەرلىك كۈتۈپخانىلارنى قاچىلاش
npm install

# 2. Windows ئۈستەلئۈستى قۇراشتۇرغۇچىسى (Electron) نى قاچىلاش
npm install -D electron electron-builder

# 3. رەسمىي Windows Setup.exe قاچىلاش ھۆججىتىنى ھاسىل قىلىش
npm run dist:win
```

تۈگىگەندىن كېيىن `release/` قىسقۇچىنىڭ ئىچىدە:
- **`Tepekkur-Buliqi-Setup-1.0.0.exe`** (ئادەتتىكىدەك قوش چېكىپ قاچىلايدىغان، ئۈستەلئۈستىگە لوگو چىقىرىدىغان رەسمىي قاچىلىغۇچ) ھاسىل بولىدۇ.

> **قاچىلىماي بىۋاسىتە ئىجرا قىلىنىدىغان يېنىك نۇسخا (Portable `.exe`) كېرەك بولسا:**
> ```bash
> npm run dist:portable
> ```

## مەخپىيەتلىك كاپالىتى
- پىروگرامما پۈتۈنلەي تورسىز (Offline) ھالەتتە كومپيۇتېرىڭىزدا ئىجرا بولىدۇ.
- بارلىق خاتىرىلەر، PDF كىتابلار ۋە رەسىملەر پەقەت ئۆز كومپيۇتېرىڭىزدىكى يەرلىك ساقلىغۇچتا تۇرىدۇ.
- قاچىلاشنى ئۆچۈرگەندىمۇ (`deleteAppDataOnUninstall: false`) شەخسىي خاتىرىلىرىڭىز ئېھتىياتسىزلىقتىن ئۆچۈپ كەتمەيدۇ.
